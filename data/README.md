# data フォルダ(つよさの表)の なおしかた

ゲームの数字は、このフォルダの CSV ファイルで決まります。
Numbers か Excel で開いて数字を直し、保存すれば、ゲームに反映されます。

## 直しかた

1. Finder でこのフォルダを開き、直したいファイル(下の表を見てください)を Numbers か Excel で開く
2. 数字を直す
3. 保存する
   - **Numbers**:メニューの「ファイル」→「書き出す」→「CSV…」を選びます。テキストエンコーディングは「Unicode(UTF-8)」にします。同じ名前で、このフォルダに上書き保存してください。
   - **Excel**:「ファイル」→「名前を付けて保存」で、ファイル形式を「CSV UTF-8(コンマ区切り)」にします。ふつうの「CSV」で保存しても読めます。
4. Mac でゲームを開いて(http://localhost:8000)、ページを読み込み直して確かめる
5. よければ、Claude に「公開して」と伝える(Fire に反映されます)

書きまちがいがあっても、ゲームは止まりません。タイトル画面に赤い枠で「何行目の何がおかしいか」が出ます。

## 共通のきまり

- **1行目(項目名)は変えないでください。** 列の順番は入れかえても大丈夫です。
- `id` は、ほかの表やマップから呼ぶときの名前です。**変えると つながりが切れる**ので、名前を変えたいときは「なまえ」の列を直してください。
- 「なまえ」などの文章に漢字やカタカナを使うときは、ふりがなを `{漢字|かんじ}` `{カタカナ|かたかな}` の形で書きます。
  - 例:`ぐるぐる {アタック|あたっく}`
- 数字は半角でも全角でも大丈夫です。

## party.csv(みかた)

主人公と なかまの、レベルごとの強さです。1行が1レベルぶんです。

| 項目 | 意味 |
|---|---|
| id | だれか(主人公は `hero`、ハモは `hamo`) |
| なまえ | 主人公の名前はゲームの最初に入力するので、ここは使いません |
| レベル | レベル |
| けいけんち | このレベルになるのに必要な、けいけんちの合計 |
| HP / MP | そのレベルでの最大HP・最大MP |
| こうげき / ぼうぎょ / すばやさ | そのレベルでの強さ(すばやさが高いと先に動く) |
| まりょく / せいしん | じゅもんの強さ / じゅもんへの守り |
| おぼえる わざ | このレベルで覚えるわざ・じゅもんの id(skills.csv)。2つ以上はスペースで区切る |

レベルを増やしたいときは、行を足してください(例:11レベル)。

なかま(ハモ)の レベルは主人公と同じです。けいけんちの列は主人公の行だけを使います。

## enemies.csv(てき)

| 項目 | 意味 |
|---|---|
| id | マップから呼ぶときの名前(`maps/forest.js` の `party` に書く) |
| なまえ | 戦闘で出る名前 |
| みため | 絵。`きのこ` `どんぐり` `はっぱ` `ゾンビねこ` `ほねほね` のどれか(絵を増やすときは Claude に頼む) |
| うごき | `うろうろ`(おいかけてこない)/ `ゆっくり`(ゆっくり おいかけてくる)/ `はやい`(主人公と同じ速さで おいかけてくる) |
| HP / MP | 最大HP・MP |
| こうげき / ぼうぎょ / すばやさ | 強さ |
| まりょく / せいしん | じゅもんの強さ / じゅもんへの守り |
| けいけんち | 倒したときにもらえる けいけんち |
| おかね | 倒したときにもらえる お金(円) |
| よわい / つよい | ぞくせい(`ほのお` `みず` `かみなり` `かぜ`)。よわいと 1.5倍、つよいと 半分のダメージ。2つ以上はスペースで区切る。なければ空でOK |
| わざ | 使うわざの id(skills.csv)。なければ空でOK |
| おとすもの | 倒したときに ときどき落とす物の id(items.csv)。なければ空でOK |
| かくりつ | おとすものを落とす確率(0〜100 の %)。50 なら 2回に1回くらい |

同じ絵で、色ちがい・強さちがいの敵を作ることもできます(id と なまえ を変えて、みためは同じにする)。

**よるだけ出る敵**は、マップ(`maps/village.js` `maps/forest.js` など)で `night: true` を付けて置きます。出てくる場所は毎回ランダムで、地面から出てきます。朝になると いなくなります。
夜の敵は、主人公のレベルが4以上だと、1レベルごとに15%強くなります(HP・こうげきなど。もらえる けいけんち・おかね も増えます)。

## skills.csv(わざ・じゅもん)

| 項目 | 意味 |
|---|---|
| id | 名前 |
| なまえ | 戦闘で出る名前 |
| ぶんるい | `わざ`(こうげき・ぼうぎょで計算)か `じゅもん`(まりょく・せいしんで計算) |
| ぞくせい | `なし` `ほのお` `みず` `かみなり` `かぜ` |
| MP | 使うMP |
| こうか | `こうげき` / `かいふく` / `じょうたい`(ダメージなしで ステータス いじょう だけ)/ `ワープ`(行ったことのある町へ。戦闘では使えない)/ `まもる`(その ターン、なかまへの こうげきを かわりに受けて、ダメージ半分) |
| あいて | `ひとり`(てき1体)/ `ぜんぶ`(てき全部)/ `じぶん` |
| いりょく | こうげき:ふつうのこうげきを 100 としたときの強さ(70 なら 0.7倍)。かいふく:回復するHPの量(+ まりょく÷2) |
| せつめい | メモ(今はゲームには出ません) |

**ダメージの計算**
- わざ・たたかう:(こうげき × いりょく ÷ 100)−(あいての ぼうぎょ ÷ 2)。たまに 1.5倍の「すごい いちげき」、5%で よけられる。
- じゅもん:(まりょく × いりょく ÷ 100)−(あいての せいしん ÷ 2)。よけられない。
- そのあと ぞくせいで 1.5倍 / 半分。毎回 ±15% くらい ばらつきます。

### ステータス いじょう(skills.csv の じょうたい・かかりやすさ)

| じょうたい | 効果 |
|---|---|
| ねむり | 1〜3ターン動けない。こうげきを受けると起きる |
| どく | ターンの終わりに 最大HPの 1/10 減る |
| しびれ | 3ターンの間、半分くらいの確率で動けない |
| わらい | 1回休み |
| くさい | 3ターンの間、こうげき(物理)が 7割になる |

- `じょうたい` に上のどれかを書くと、その わざ が当たったときに かかります。`かかりやすさ` は 0〜100(%)。空なら かかりません。
- 敵にも味方にも かかります。**戦いが終わると全部治ります**。道具「なおりぐさ」(しゅるい `なおす`)でも治せます。

## items.csv(どうぐ・そうび)

| 項目 | 意味 |
|---|---|
| id | マップから呼ぶときの名前(`give: 'かいふくやく'` のように使う) |
| なまえ | ゲームで出る名前 |
| しゅるい | `かいふく`(戦闘やメニューで使える)/ `よろい`(ぼうぎょが上がる)/ `ぶき`(こうげきが上がる)/ `なおす`(ステータス いじょうを治す。戦闘で使う)/ `ざいりょう`(さぎょうだいで使う)/ `ワープ`(行ったことのある町へ とぶ)/ `だいじ`(だいじな もの) |
| こうか | かいふく:回復するHP。よろい・ぶき:上がる数字 |
| みため | よろい:`ぬの` `かわ` `てつ`(服の色が変わる)。ぶき:`ぼう` `けん`(手に持つ絵)。それ以外は空でOK |
| ねだん | お店で買うときの ねだん(円)。売るときは半分。0 や空なら売り買いできない |
| せつめい | メニューの「どうぐ」で出る説明 |

よろい・ぶきは、手に入れても自動では装備しません。メニューの「そうび」で着がえます。

**お店で何を売るか**は `maps/shop.js` の `shop: [...]` に items.csv(かぐやは furniture.csv)の id を並べて決めます。

## furniture.csv(かぐ)

| 列 | 意味 |
|---|---|
| id | マップやお店から呼ぶときの名前 |
| なまえ | ゲームで出る名前 |
| みため | 絵:`ベッド` `タンス` `たな` `はなびん` `いす` `テーブル` `うえき` `ぬいぐるみ` `じゅうたん` `ドラム` `ギター` `マイク` `さぎょうだい` `ランプ` `ほねのいす` `き` |
| ねだん | かぐやで買うときの ねだん(円)。売るときは半分 |
| せつめい | しらべたときと、お店で出る説明 |

- みためで働きと大きさが決まります。`ベッド`(たて2マス)は ねると回復、`さぎょうだい` は ものを作れる、`テーブル` は よこ2マス、`じゅうたん` は 2×2マスで上を歩けます。`ランプ` は 夜の部屋を明るくします。
- 同じ絵で別の かぐ を作ることもできます(id と なまえ を変えて、みためは同じにする)。
- 主人公の家に最初から置いてある かぐ は `maps/home.js` の `furniture` で決めます。

## recipes.csv(さぎょうだいの つくりかた)

| 列 | 意味 |
|---|---|
| つくるもの | できる物の id(items.csv か furniture.csv) |
| ざいりょう1〜3 | 使う ざいりょうの id(items.csv)。使わないところは空でOK |
| かず1〜3 | その ざいりょうを いくつ使うか |

新しい町や お話に進んだときに、行を足して つくりかたを増やしていきます。

## time.csv(ひると よるの ながさ)

| なまえ | ふん |
|---|---|
| ひる | 昼の長さ(分)。はじめは 6 |
| よる | 夜の長さ(分)。はじめは 2 |

- 時間は、外(村・森)にいるときだけ進みます。家やお店の中では止まります。
- 夜に家のベッドで寝ると、朝になります。
